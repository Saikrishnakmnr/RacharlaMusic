# RacharlaMusic — Free Build

Free RacharlaMusic Streamlit app with the original neon/glass UI.

This build does **not** use ACE-Step, MiniMax Music 3, or Gemini/Lyria.
It tries the newer public YuE2-3B and DiffRhythm2 music Spaces and includes a no-key free lyrics assistant.

The public music Spaces can have queue/capacity/availability limits outside this app's control. The app never displays a successful download unless actual audio was received and validated.
